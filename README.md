# MyMothership — модуль Foundry для Mothership 1e

Версия 0.2.0. Foundry 13, система `mothership-fr` 1.8.21.

## Что внутри
- Русский перевод интерфейса системы: листы персонажей, существ и кораблей, окна, сообщения в чате (427 строк из `lang/fr.json` системы).
- Настройка **«Язык интерфейса Mothership»** (Настройки → Configure Settings → вкладка модуля): «Русский» или «Язык системы (французский)». Каждый игрок выбирает для себя, после смены страница перезагружается.
- Фразы, которые система вписывает в чат и окна прямо в коде («SUCCESS!», «Vous n'avez pas obtenu moins que votre…», «augmente from … to …», урон), подменяются на русские при показе (`scripts/text-ru.js`).
- Ключи, которые система использует, но которых нет в её `fr.json` (кнопки «Преимущество / Обычный / Помеха» и ещё ~50), добавлены в перевод.
- Окна выбора броска («Преимущество / Обычный / Помеха») подгоняются по высоте: в системе у них жёсткая высота, и подпись «Выберите тип броска» налезала на кнопки (`styles/mymothership.css`, `scripts/main.js`). Если ключ перевода кнопок почему-то не сработал, их подписи переводятся по тексту.
- Фраза под броском в чате собирается по-русски целиком: «Выпало меньше Силы.», «Выпало не меньше Страха с навыком …». Формулы бросков подписываются по-русски: к100, 2к10 (сам бросок не меняется).
- Подписи бросков в чате («Проверка силы», «Испытание страха») система хранит прямо в персонажах. Смотритель при входе переводит их у всех актёров мира на свой выбранный язык; новые актёры создаются сразу с русскими подписями.

## Загрузка папки в плейлист
Опция «Загрузка папки в плейлист» (включена по умолчанию, выключается в настройках модуля). Смотритель кликает правой кнопкой по плейлисту → **Загрузить папку…** или жмёт **Загрузить папку** в настройках плейлиста, выбирает папку в хранилище — и все аудиофайлы из неё добавляются разом, по алфавиту. Уже добавленные треки повторно не попадают. Подпапки не просматриваются.

## Что не переводится
- Содержимое компендиумов системы (классы, навыки, оружие, таблицы) — оно французское. Материалы ваншота «Восходящий поток» модуль будет приносить на русском.
- Результаты таблиц из компендиумов (паника, раны) — это содержимое компендиумов, оно французское.
- Редкие фразы из кода системы, которые ещё не попали в `scripts/text-ru.js`: присылайте скриншот — добавим правило.
- Интерфейс самого Foundry — для него есть отдельный модуль русского перевода ядра.

## Термины
По карточке Mothership в Мастерской: испытание, проверка, раны, ПБ, ББ, знаток / эксперт / мастер, лояльность, инстинкты, отпуск, смотритель.

## Установка
Foundry → Add-on Modules → Install Module → поле Manifest URL:

`https://raw.githubusercontent.com/brigadapoum/mymothership/main/module.json`

Потом включить модуль в мире: Настройки → Manage Modules.
