# MyMothership — модуль Foundry для Mothership 1e

Версия 0.3.0. Foundry 13, система `mothership-fr` 1.8.21.

## Что внутри
- Русский перевод интерфейса системы: листы персонажей, существ и кораблей, окна, сообщения в чате (427 строк из `lang/fr.json` системы).
- Перевод подключает сам Foundry — и при английском, и при русском языке Foundry (раздел `languages` в `module.json`). Скрипт модуля для этого не нужен, поэтому перевод не слетает, даже если скрипт не загрузился.
- Настройка **«Язык интерфейса Mothership»** (Настройки → Configure Settings → вкладка модуля): «Русский» или «Французский (язык системы)». Каждый игрок выбирает для себя, после смены страница перезагружается.
- Если перевод всё же не подключился, смотритель при входе видит красное сообщение об этом.
- Фразы, которые система вписывает в чат и окна прямо в коде («SUCCESS!», «Vous n'avez pas obtenu moins que votre…», «augmente from … to …», урон), подменяются на русские при показе (`scripts/text-ru.js`).
- Ключи, которые система использует, но которых нет в её `fr.json` (кнопки «Преимущество / Обычный / Помеха» и ещё ~50), добавлены в перевод.
- Окна выбора броска («Преимущество / Обычный / Помеха») подгоняются по высоте: в системе у них жёсткая высота, и подпись «Выберите тип броска» налезала на кнопки (`styles/mymothership.css`, `scripts/main.js`). Если ключ перевода кнопок почему-то не сработал, их подписи переводятся по тексту.
- Фраза под броском в чате собирается по-русски целиком: «Выпало меньше Силы.», «Выпало не меньше Страха с навыком …». Формулы бросков подписываются по-русски: к100, 2к10 (сам бросок не меняется).
- Подписи бросков в чате («Проверка силы», «Испытание страха») система хранит прямо в персонажах. Смотритель при входе переводит их у всех актёров мира на свой выбранный язык; новые актёры создаются сразу с русскими подписями.

## Восходящий поток — экипаж (компендиум)
Компендиум **«Восходящий поток — экипаж»** в папке «Восходящий поток» вкладки Compendium Packs. Виден только смотрителю (у игроков доступа нет — в листах тайны).

- **Рекомендуемая четвёрка:** Лола Ковальчик (специалист), Йоко Танабэ (учёный), Дана Крюгер (морпех), Тед (андроид).
- **Остальной экипаж:** Рут Окафор, Микко Лахти, Карим Хаддад, Ханна Отиено, Бернард Оке, Тео Хольм — запасные прегены, а неразобранные становятся NPC.
- **Капитан (NPC):** Аугусто Ферро.

В каждом листе: характеристики и испытания по 1e, здоровье, раны, стресс 2, реакция на травму класса, навыки с рангами, надетая броня, оружие, снаряжение, безделушка и нашивка, кредиты. Портрет и круглый токен (токен привязан к актёру, полосы — здоровье и стресс).
- **Био** — что видно со стороны: вид, манера, чем думает, желание, польза, близкие на станции, где персонаж в момент удара.
- **Заметки** — для игрока этого персонажа: тайна (у Теда — закрытый приказ Компании), как голосует, где ломается, связи; блок «Смотрителю» — как вести, если персонаж достался игроку или остался NPC.

**Как раздать:** правый клик по прегену в компендиуме → Import Entry (или перетащить в Actors) → в мире правый клик по актёру → Configure Ownership → игроку «Owner». Шесть неразобранных можно импортировать как NPC.

Цифры и тексты — из комнаты ваншота («01 Экипаж — прегены», «03 Экипаж — цифры (1e)»). Исходники компендиума — `src/packs/vp-crew/`, генератор — `tools/pregens.py`.

**Портреты:** Víctor Jiménez Merino (Ashen Victor), *Sci-Fi Character Portraits*, лицензия CC BY-NC 4.0 — только некоммерческое использование.

## Загрузка папки в плейлист
Опция «Загрузка папки в плейлист» (включена по умолчанию, выключается в настройках модуля). Смотритель кликает правой кнопкой по плейлисту → **Загрузить папку…** или жмёт **Загрузить папку** в настройках плейлиста, выбирает папку в хранилище — и все аудиофайлы из неё добавляются разом, по алфавиту. Уже добавленные треки повторно не попадают. Подпапки не просматриваются.

## Что не переводится
- Содержимое компендиумов системы (классы, навыки, оружие, таблицы) — оно французское. Материалы ваншота «Восходящий поток» модуль будет приносить на русском.
- Результаты таблиц из компендиумов (паника, раны) — это содержимое компендиумов, оно французское.
- Редкие фразы из кода системы, которые ещё не попали в `scripts/text-ru.js`: присылайте скриншот — добавим правило.
- Интерфейс самого Foundry — для него есть отдельный модуль русского перевода ядра.

## Термины
По карточке Mothership в Мастерской: испытание, проверка, раны, ПБ, ББ, знаток / эксперт / мастер, лояльность, инстинкты, отпуск, смотритель.

## Сборка
`npm install` (один раз), потом `npm run build` — собирает компендиумы и `dist/mymothership.zip`; `npm test` проверяет, что в архиве есть всё, на что ссылается `module.json`. Ссылка `download` указывает на архив конкретной версии (тег `vX.Y.Z`), поэтому кэш GitHub не подсовывает старый архив к новому манифесту.

## Установка
Foundry → Add-on Modules → Install Module → поле Manifest URL:

`https://raw.githubusercontent.com/brigadapoum/mymothership/main/module.json`

Потом включить модуль в мире: Настройки → Manage Modules.
